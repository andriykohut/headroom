# headroom-cli

The `headroom` command: report Claude Code usage from your machine to a
relay you host, and serve it to the Headroom Android app.

Published as `headroom-cli` because the name `headroom` on crates.io
belongs to an unrelated, abandoned crate. The installed binary is
`headroom`.

Full documentation, including how to run the relay and pair a phone:
<https://github.com/andriykohut/headroom>
